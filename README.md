# 🎵 Spotify Redesign

A Spotify-inspired music web experience built from scratch with HTML and CSS.  
The project focuses on recreating the look and feel of a modern music streaming platform while building a clean, responsive, multi-page interface.

🔗 **Live Demo:** https://nakuljain789.github.io/Spotify-Redesign/

---

## ✨ Features

- 🎧 Spotify-inspired dark-themed UI
- 🏠 Home page with trending and recommended songs
- 🎵 Playlist details page
- 🔍 Search bar interface
- 📚 Library/sidebar navigation
- 💿 Album and playlist artwork
- 📋 Track listing with artist and duration
- 🔗 Multi-page navigation
- 📱 Responsive layout
- 🎨 Custom styling using CSS
- 📐 Flexbox-based layouts
- 🖼️ Local image assets for album artwork

---

## 📄 Pages

### 🏠 Home
The main landing page featuring:
- Navigation bar
- Music library/sidebar
- Trending songs
- Recommended songs
- Album artwork
- Music cards

### 🔎 Browse
A dedicated page for exploring music categories and playlists.

### 🎵 Playlist
A detailed playlist view containing:
- Playlist cover
- Playlist title
- Description
- Playlist information
- Play and Follow buttons
- Track list
- Artist names
- Track durations
